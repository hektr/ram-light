Privacy Policy for RAM Light

Last updated: November 2026

RAM Light is a lightweight Chrome extension designed to monitor system memory and help users free up RAM by discarding inactive tabs. 
  
1. Data Collection  
RAM Light does NOT collect, store, process, or transmit any personal data, browsing history, or user information. All operations are performed entirely locally on your device.
  
2. Use of Permissions  
- system.memory: This permission is used exclusively to read the total and available RAM on your local machine to display it in the extension popup and badge. This data never leaves your device.
- tabs (isn't used yet, but planned in future version 2.1): This permission is used solely to identify inactive, non-pinned background tabs and trigger the native chrome.tabs.discard() API to free up memory. RAM Light does NOT read, modify, or track the content, URLs, or titles of your tabs.
  
3. Third-Party Sharing  
We do not share any data with third parties, as no data is collected or transmitted.
  
4. Contact  
If you have any questions about this Privacy Policy, please contact us via the support link provided in the Chrome Web Store listing.
